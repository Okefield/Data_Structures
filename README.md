# Systeme und Netze – 4IA

Dieses Repository dient als zentrale Sammlung für Aufgaben, Übungen und Projekte im Rahmen des Fachs **Systeme und Netze** der 4IA.

## Inhalte

### `LinkedList`
Dieses Modul umfasst die Implementierung einer einfach verketteten Liste für `double`-Werte. Folgende Funktionen sind implementiert:

- `ll_push`: Fügt ein Element am Anfang der Liste hinzu.
- `ll_pop`: Entfernt das erste Element der Liste und gibt den Wert zurück.
- `ll_add`: Fügt ein Element an einer spezifischen Position ein.
- `ll_rm`: Entfernt ein Element an einer spezifischen Position.
- `ll_clear`: Löscht die gesamte Liste und gibt den Speicher frei.
- `ll_to_array`: Kopiert die Daten der Liste in ein Array.
- `ll_getLength`: Ermittelt die aktuelle Anzahl der Elemente in der Liste.

Weitere Themen werden im Laufe des Schuljahres ergänzt.

## Technologien
Der Fokus der Implementierungen liegt auf der Programmiersprache **C**.
